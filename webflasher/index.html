🌱 Pflanzensensor flashen

Firmware direkt aus dem Browser per USB auf den Pflanzensensor spielen – ohne Programmierumgebung.

Änderungen

2. Anschließen und installieren

Pflanzensensor mit einem Datenkabel anschließen, dann:

Dieser Browser kann nicht auf USB zugreifen. Bitte Chrome, Edge oder Opera auf einem Computer verwenden. USB-Zugriff ist nur über HTTPS erlaubt.

Kein Gerät in der Liste? Treiber für den USB-Chip installieren (CP210x bzw. CH340) und ein anderes Kabel probieren.

Was dabei passiert

  • Einstellungen bleiben erhalten. Nur die Firmware wird ersetzt; WLAN, Sensoren, Chronik und Log bleiben auf dem Gerät. Das Kästchen „Gerät löschen“ nur ankreuzen, wenn wirklich alles weg soll.
  • WLAN einrichten (nur bei neuen Geräten nötig). Hat das Gerät noch kein WLAN, bietet der Assistent nach dem Flashen an, eins einzutragen – es landet in WLAN-Slot 1. Der Schritt lässt sich überspringen; das Gerät öffnet dann einen eigenen Zugangspunkt zur Einrichtung. Bei eingerichteten Geräten kommt der Schritt nicht; über „Verbinden“ → „WLAN ändern“ geht es trotzdem.
  • Von Firmware 2.x: vorher in der alten Oberfläche die Konfiguration herunterladen. Firmware 3 räumt beim ersten Start die alten Dateien weg; danach unter Admin → Einstellungen → „Konfiguration hochladen“ wieder einspielen.
  • Später geht jedes Update auch ohne Kabel über Admin → Update im Gerät.
